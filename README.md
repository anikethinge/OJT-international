# EventPass — Orbit Portal

**Live Demo:** https://anikethinge.github.io/OJT-international/

A Liquid Glass event pass and role-based campus check-in portal featuring spring-physics controls, Dusk/Lagoon theme switching, password strength and Caps Lock guards, Organizer PIN verification, and a post-login pass workspace (`home.html`).
